# Bronnen

Centraal register van alle bronnen in dit dossier. Eén plek, met volledige citatie, type,
hardheid en verificatiestatus. Notities verwijzen met het **bron-ID** (`[P1]`, `[M2]`, `[T16]`…).

## ID-schema (per laag)
- **P** — Piketty / elite-facties (laag 1, theorie)
- **S** — SCP / Nederlandse machtselite (laag 1, NL)
- **M** — Media / eigendom (laag 2)
- **T** — Transnationaal + theorie/falsifieerbaarheid (lagen 3–4)

## Verificatielegenda
- ✅ **verbatim** — exacte bewoording primair opgehaald.
- 🟡 **deels** — citatie/feit bevestigd, maar quote via mirror/secundaire bron of alleen abstract.
- ⚠️ **onbevestigd** — niet primair te verifiëren (paywall/socket/betwist); niet als hard
  presenteren.

## Werkwijze bij toevoegen
1. Geef de bron het eerstvolgende vrije ID in haar laag.
2. Vul: volledige citatie · URL · type/hardheid · verificatiestatus · "gebruikt in".
3. Verwijs er vanuit de notitie naar met het ID; zet relevante verbatim quotes in de notitie,
   niet hier (dit blijft een register).

Het volledige register staat in **`bronnenregister.md`**.
