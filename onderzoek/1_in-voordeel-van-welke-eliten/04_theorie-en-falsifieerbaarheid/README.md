# Laag 4 — Emergent, geen complot (de guardrail)

De scharnier voor het hele dossier. Hoe houden we "de bias dient de elite" *structureel en
falsifieerbaar*, in plaats van een niet-weerlegbare samenzweringsredenering?

## Notities in deze laag
- `4.1_emergent-geen-complot.md` — Herman's non-complot-frame + falsifieerbaarheidscriterium +
  Schlesingers functionalisme-waarschuwing.
- `4.2_structuur-vs-complot-financiele-mythes.md` — de guardrail in actie: de check op de
  Rothschild/Rockefeller/Fed-claims (structurele financiële macht = echt; genoemde-familie-cabal =
  niet-falsifieerbare, deels antisemitische mythe).

## De kernregel (toepasbaar op elke claim in dit dossier)
Een claim blijft *structureel/emergent* zolang ze:
1. een **herleidbare structurele oorzaak** heeft (eigendom / advertentie / sourcing / flak /
   ideologie) — geen onmeetbare intentie of geheime regie;
2. een **toetsbare voorspelling** doet die ook fout kan blijken;
3. niet terugvalt op **uitkomst-als-bewijs** (functionalistische circulariteit) of op een
   **"self-sealing" cabal** die elk tegenbewijs tot bewijs omvormt.

Dit sluit aan op de modelmechaniek (`INVLOED-PRIOR`-check, contradictie-cap). Hardheidsvolgorde:
laag 1–2 + 3.1/3.7 (structurele drivers) zijn het minst complot-gevoelig; laag 3.3/3.6
(technocratie, neoliberale hegemonie) het meest — daar is een toetsbare operationalisering nodig.
